# Hangman Game 🎮

## Project Description

Hangman is a word guessing game developed using Python.
The player has to guess the hidden word by entering one letter at a time.

## Features

- Random word selection
- Letter-by-letter guessing
- 6 wrong attempts allowed
- Correct and incorrect guess detection
- Prevents repeated guesses
- Win and game-over messages

## Technologies Used

- Python
- VS Code

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python hangman.py
